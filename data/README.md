# Data

No data are committed to this repository.

> All input datasets used in this study are publicly available from official data repositories, subject to the access, registration, citation, and licensing conditions of the respective data providers. Raw third-party datasets are therefore not redistributed in this repository.

| Dataset | Role | Official access |
|---|---|---|
| FLUXNET (+ AmeriFlux, ICOS, OzFlux records) | EC GPP, meteorology, wind direction, IGBP metadata | <https://fluxnet.org/data/data-policy/> · <https://ameriflux.lbl.gov/> · <https://data.icos-cp.eu/> · <https://ozflux.org.au/> |
| GOSIF | Satellite SIF | <https://globalecology.unh.edu/data/GOSIF.html> |
| GOME-2 SIF v2 | Satellite SIF | <https://doi.org/10.3334/ORNLDAAC/2292> |
| TROPOSIF | Satellite SIF | <https://s5p-troposif.noveltis.fr/> |
| OCO-3 SIF Lite | Satellite SIF | <https://disc.gsfc.nasa.gov/> |
| Global Aridity Index v3.1 | Aridity context | <https://doi.org/10.6084/m9.figshare.7504448> |
| NASA POWER | Precipitation context | <https://power.larc.nasa.gov/> |
| MODIS MYD21C1 v061 | LST panels | <https://doi.org/10.5067/MODIS/MYD21C1.061> |

Full details, versions, caveats and citation requirements: [docs/data_availability.md](../docs/data_availability.md).

`data/example/` is reserved for small, clearly labelled example files; none are currently included.
